## 1. Neon
New Project → agromarket → AWS Frankfurt → Connect → Copy snippet. Создайте `.env.neon`:
DATABASE_URL, ADMIN_EMAIL, ADMIN_PASSWORD (длинный, не Admin12345). Затем:
    node --env-file=.env.neon db/seed.js            # предохранитель ОТКАЖЕТ — запишите текст
    node --env-file=.env.neon db/seed.js --force    # один раз
    node --env-file=.env.neon db/migrate.js

## 2. Render (Web Service из agromarket-server, ветка main, Frankfurt, Free)
- Build: `npm ci --omit=dev`   Start: `npm run db:migrate && npm start`
- Переменные: NODE_ENV=production, DATABASE_URL, JWT_SECRET (64 символа), JWT_EXPIRES_IN=2h,
  CORS_ORIGIN=http://localhost:5173 (адрес Vercel добавите позже)
- Health Check Path `/api/health`, Auto-Deploy **Off**
- Settings → Deploy Hook → скопировать URL

## 3. Vercel (agromarket-react)
- Project Name agromarket-ЛОГИН, Vite, переменная VITE_API_URL=https://agromarket-api-ЛОГИН.onrender.com/api
- Потом на Render: CORS_ORIGIN=https://agromarket-ЛОГИН.vercel.app,http://localhost:5173 (без / в конце!)
